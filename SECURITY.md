# Security

This is an experimental, trusted-local tool. Generated code and declared tests
run with the user's local authority; execution is not sandboxed. Loopback
services are not designed for public or multi-user deployment. Vendor CLIs,
accounts, and model services retain their own security and usage boundaries.

Report vulnerabilities privately using this repository's GitHub **Security →
Report a vulnerability** feature. Include affected commits, reproduction steps,
and impact. Do not put credentials or exploitable details in public issues.
Only the current main branch is maintained during the preview; there is no
response-time or production-support guarantee.
